# 中期答辩：数据集制作演示

纯静态页面，图纸队列共 12 套：10 套人工示例（2107、2108、2110、2111、2115、2125、2126、2128、2135、2142）、Astra 历史测试、千问历史测试。两个模型使用同一套 ID1002 原图，各自独立保存；千问使用内部样本编号 1002002 避免草稿冲突。共 22 张不同原图，发布目录仅包含这些图、必要的几何及历史评估摘要；其余数据集、原始模型响应、密钥和后端保持私有。

ID1002 默认显示此前 `gpt-6-astra` 测试保存的 42 个原始候选体块，可通过上方结果类型选择人工数据对照（26 个体块），再点载入；切换可撤回。保留历史候选估算尺度 13500×8700 mm，另列人工真实尺寸 14100×9900 mm，不缩放、修正或冒充人工数据。历史召回率 73.1%、精确率 45.2%（同类同层框 IoU≥0.5），功能区域像素 IoU 69.3%，均来自已有评估文件，当前编辑不重算指标。楼梯、重叠和漏块错误原样保留。可通过 `?case=1002` 直接打开；没有重新调用模型。

千问样本保留 `qwen3-vl-plus` 当时生成的 23 个候选体块和估算尺度，可独立切换至同一份 26 体块人工对照。历史召回率 50.0%、精确率 56.5%、功能区域像素 IoU 47.4%；原始楼梯高度、重叠及漏块问题未修正。通过 `?case=1002002` 直接打开。Astra 与千问的浏览器草稿、切换和撤回互不覆盖；没有重新调用模型。

页面支持两层校准与对齐、300 mm 体块绘制、功能分类、实时三维预览、撤回重做、几何检测，以及草稿和几何 JSON 下载。通过“体块标注”开关对照原图与标注结果。

内置 10 套案例已执行墙线到固定体块边界的自动配准，打开即载入底图变换，并以住宅标注范围适配视图，排除未标注院子和图纸留白。20 张图中 18 张通过自动检查；ID2107 二层、ID2125 二层作为“局部边界需复核”的候选展示。该检查不代表人工验收，不改变真实尺寸或体块。编辑面板显示各层状态，仍可手动对应点配准。旧浏览器草稿在几何未改变时更新底图变换；人工配准、已修改的几何和显式撤销配准均保留。

配准侧录保存在 `data/05_review_drafts/registration_walls_v1.json`。算法用长横竖墙线的距离图匹配去重后的体块边界，检查两个方向和四个区域，并校验图像与几何摘要；没有使用视觉模型调用或重新估算建筑尺寸。计算：`python -m plan_review.auto_registration 2107`，随后重新构建。样例中的两套独立评估案例仅在开发样例确定流程后按固定配置执行，不据其结果调参。

“载入预置标注”读取提前制备的示例数据，不是实时模型推理。本地上传需要分别选择两层图并填写尺度，随后手工制作体块；不存在浏览器侧模型密钥或在线识别请求。

上传图片、草稿及修改使用 IndexedDB 保存在当前浏览器，刷新后仍可打开；不上传至服务器，不修改正式数据集。清理站点数据或换浏览器不会保留本地进度，答辩前请下载草稿留存。

构建：在项目根目录执行 `python website/scripts/build-dataset-demo.py`。构建复用现有工作台界面与操作代码，浏览器数据适配器源文件在 `website/scripts/dataset-demo-adapter.js`。测试：`node website/scripts/test-dataset-demo.cjs`，使用 Playwright 与 Chromium。

发布到 SpaceModal 根目录下的 `/dataset-studio/`。无需 Python 云服务器、登录账号或付费服务器。
