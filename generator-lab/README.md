# 拓扑优先生成试验

独立开发页面 `/generator-lab/`，不替换线上 `/generator-studio/`。自然语言由保管密钥的代理解析；模型推理和网格生成在浏览器运行。默认示例建议 12×12 米，三卧两卫，预算32。

## 设计规范与实现状态

用户新增的矩形满铺、300mm三维体素、楼梯贯通与简单形状要求，以及大模型—生成器反馈闭环，详见[协同生成流程与设计规则](DESIGN_RULES.md)。本分支已实现矩形满铺、独立R1–R6校验和有界反馈闭环；所有返回候选必须通过规则与目标硬关系检查。完整建筑设计验收仍未覆盖。

## 本地预览

安装 Node.js 后，在网站仓库运行 `node scripts/serve-generator-lab.mjs`，打开 `http://127.0.0.1:8898/generator-lab/`。代理从环境变量 `PARSER_API_KEY` 或 `DASHSCOPE_API_KEY` 读取密钥，也支持用 `SPACEMODAL_ENV_FILE` 指向仓库外的环境文件。密钥不进入网页、Git或导出文件。没有密钥时，在连接设置切换“本地策略”。

## 流程

1. 代理生成房间实例、楼层、面积偏好及目标贴邻关系。用户可以先审阅拓扑，再确认生成。必需关系与偏好关系分别标记。
2. 进入确认卡片前，系统规则可补齐缺失的公共联系；没有公共节点时，仅在用户未禁止且数量允许的范围内补齐默认走道，改动明确显示供审阅。用户未指定贴邻时，系统按公共联系规则整理模型推断关系，其他推断联系保留为偏好；用户明确提出的贴邻不被放宽。空图或非法实例仍会拒绝。随后校验11类功能、必需房间、数量、楼层、面积容量和目标图连通。明确取消的可选功能数量保留到后续对话；模型违反这些要求时返回错误。
3. 使用现有 HGNN_CVA 权重推理空间偏好，保持原模型推理接口。没有重新训练，也没有声称该模型已学习任意输入拓扑。
4. 用矩形片对整个矩形楼层完整分区；楼梯当前固定为2.4×2.4米矩形，在两层保持同位，房间为矩形或L型。实例归属与功能标签分开保存，不允许空值、切角和碎片。算法目前采用可旋转的公共带分区与房间分组，仍是受限的布局语法，不保证任意拓扑可实现。
5. 独立展开20层体素检查R1–R6，另检查最低面积与目标必需贴邻。失败先尝试矩形片交换；在线模式随后把容量/关系证据反馈大模型，最多修订3次、总时限180秒。本地模式不调用模型，直接展示失败报告。
6. 自动修订冻结全部已确认实例、功能、楼层、数量和必需关系，明确要求的楼梯居中/靠边会锁定；只允许未锁定组织模式、面积偏好和软关系调整。每轮重新推理、生成、校验；不允许通过降低规则或删房间获得成功。
7. 展示平面、三维、目标/实际关系及每轮报告。JSON包含20层体素映射、规则报告和历史；离线HTML包含平面、三维、A4拓扑与检查记录。每轮搜索种子由确认种子和轮次确定性派生，并记录实际值。

## 边界

这是概念阶段原型，`project_accepted` 保持 `null`。贴邻检查不证明门、真实通行、疏散、采光或结构合理性；目标面积是偏好，当前评分不保证达到精确面积。本版本不支持庭院、挑空和空值区域。默认组织仍以楼梯和公共空间为中心，任意复杂拓扑可能搜索失败。紧凑边界和高房间数量不保证成功，不能将6–18米的输入范围理解为全部可生成范围。

代理新增 `/design`，原 `/parse` 保持兼容。上线实验版前需打包共享 `generator-lab/design.js` 模块、部署代理，并配置HTTPS `/design` 地址；本分支没有修改现有托管代理或生产网页。调用限制仍是单实例内存统计，不是持久的账户计费上限。

## 验证

- `node server/parser/scripts/test-proxy.mjs`：原解析接口兼容、来源检查、边界、调用限制。
- `node server/parser/scripts/test-design.mjs`：拓扑连通、取消功能和后续数量保持。
- `node scripts/test-rules-cooperation.cjs`：R1–R6反例、真实失败修订、修订上限、锁定项保护、取消与时限。
- `node server/parser/scripts/test-feedback.mjs`：服务端修订约束保护。
- `node scripts/test-cooperation-ui.cjs`：网页失败、非法修订、停止操作保留已有合格结果（需先启动预览与配置浏览器路径）。
- 启动预览后运行 `node scripts/test-generator-lab.cjs`：真实模型三策略×三种子，以及页面、导出、恢复、响应布局。浏览器验证需安装Playwright；可用 `PLAN_PLAYWRIGHT_PATH` 和 `PLAN_CHROMIUM_PATH` 指定路径。

测试导出和截图写入被Git忽略的 `qa-artifacts/`。

真实代理验证需显式设置 `RUN_LIVE_MODEL=1` 后运行 `scripts/test-live-cooperation.cjs`，会调用已配置模型；例程用7.2×12米取消多功能室的中部策略触发失败，再依据报告修订。其余测试不调用付费模型。
